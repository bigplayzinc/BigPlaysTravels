NEON JAPAN ROUTE

Your plan lives in a private GitHub repo. Connect this device to it once; after that every change syncs between your devices.

Already connected on another device?

On that device open ⋯ → Connect another device, then tap Scan pairing QR here (or paste the pairing code).

First device: create a GitHub token
  1. Open GitHub → new fine-grained token.
  2. Name it “Japan Route” and set the expiration to a date after your trip.
  3. Repository access: Only select repositories → pick your plan repo.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate the token, copy it and paste it above.
