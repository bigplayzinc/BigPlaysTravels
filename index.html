NEON JAPAN ROUTE

This map runs on Google Maps with your own API key. Google's monthly free usage easily covers one person planning a trip. The key stays in this browser only.

  1. Go to Google Cloud console → Maps, create a project and add billing (required, but personal use stays in the free tier).
  2. Enable Maps JavaScript API, Places API (New) and Routes API.
  3. Credentials → Create API key. Restrict it to those three APIs and to the websites you'll open this from, e.g. http://localhost:8000/*.
  4. Run python -m http.server 8000 in this file's folder and open http://localhost:8000/ plus the file name. Or host the file on any static site.
